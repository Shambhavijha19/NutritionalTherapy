# Nutritional Therapy

A modern, responsive nutrition and wellness website built for **Dt. Shreya**, a certified nutritionist specializing in personalized, evidence-based nutrition plans.

🌐 **Live Website:** [Nutritional Therapy](https://nutritionaltherapy.netlify.app/?utm_source=chatgpt.com)
💻 **GitHub Repository:** [NutritionalTherapy on GitHub](https://github.com/Shambhavijha19/NutritionalTherapy?utm_source=chatgpt.com)

## 📌 About the Project

**Nutritional Therapy** is a professional healthcare website designed to provide information about nutritional services, consultation packages, and personalized diet planning.

The website allows visitors to explore Dt. Shreya's expertise, available nutrition services, pricing plans, FAQs, and contact information, as well as submit an appointment request.

## ✨ Features

* 🏠 Modern and responsive landing page
* 👩‍⚕️ Nutritionist profile and professional information
* 🥗 Detailed nutrition and wellness services
* 📋 Personalized meal planning information
* 💊 Therapeutic diet services
* 🧘 Nutritional counseling
* 💰 Multiple consultation packages
* 📅 Appointment booking form
* 💳 UPI payment integration/instructions
* ❓ Frequently Asked Questions section
* 📞 Contact information and social links
* 📱 Mobile-friendly responsive design
* ✅ Post-submission thank-you page

## 🛠️ Technologies Used

* **HTML5** — Website structure
* **CSS3** — Styling, layout, responsiveness, and UI
* **JavaScript** — Interactivity and form functionality
* **Netlify** — Deployment and hosting
* **FormSubmit** — Form submission handling

## 🚀 Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/Shambhavijha19/NutritionalTherapy.git
```

### 2. Navigate to the Project

```bash
cd NutritionalTherapy
```

### 3. Run the Website

Since this is a static website, no backend installation is required.

Simply open:

```text
index.html
```

in your browser.

For development, you can also use **VS Code Live Server**.

## 🌐 Deployment

The website is deployed using **Netlify** and is publicly accessible at:

[https://nutritionaltherapy.netlify.app/](https://nutritionaltherapy.netlify.app/)

Any updates pushed to the connected GitHub repository can be deployed through Netlify's continuous deployment workflow.
